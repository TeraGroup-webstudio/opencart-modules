# SAP — Login Social Networks

🛒 [Придбати на OpenCart Forum](https://opencartforum.com/files/file/9039-sap-login-social-networks-avtorizaciyareyestraciya-cherez-socialni-merezhi-one-tap-google-popup-loginregister-geoip/)

## Встановлення

1. Закидуємо весь вміст папки `upload` у корінь сайту.
2. Завантажуємо модифікацію `Login-Social-Networks-Custom-mod.ocmod` в адмінці через **Установка доповнень**.
3. Включаємо модуль **SAP - Login Social Networks**.
4. Підключаємо соцмережу і оновлюємо модифікатор.

## Інструкції для соцмереж

Дивись папку `Инструкции/`:

- Apple.pdf
- Discord.pdf
- Facebook.pdf
- Google.pdf
- LinkedIn.pdf
- Reddit.pdf
- Telegram.pdf
- Twitter.pdf
